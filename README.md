# 💻 LeetCode Solutions

Временный `README.md` для репозитория с моими решениями задач на платформе [LeetCode](https://leetcode.com/).

## 🗂 Структура репозитория

Решения распределены по тематическим папкам в зависимости от типа задач и используемых технологий:

* **`Algorithms/`** — Решения классических алгоритмических задач (массивы, графы, динамическое программирование и др.).
* **`Concurrency/`** — Задачи на многопоточность и синхронизацию.
* **`Database/`** — Решения задач по базам данных (SQL-запросы).
* **`JavaScript/`** — Задачи, решенные с использованием JavaScript.
* **`Shell/`** — Скрипты для решения задач с использованием командной оболочки Bash.
* **`pandas/`** — Решения задач на анализ данных с помощью библиотеки pandas.
